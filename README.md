### Focus Tomato

Focus Tomato 是一个面向 GNOME 的极简顶栏番茄钟。它独立于浏览器、编辑器和终端运行，仅提供专注计时、手动开始的休息、静默通知，以及当天的完成次数和实际专注时长。

##### 主要行为

- 默认 `25` 分钟专注、`5` 分钟休息。专注结束后先进入“等待休息”，点击通知或顶栏的“开始休息”才启动完整倒计时，也可以从顶栏跳过。
- 休息页始终使用纯黑背景，中央显示剩余时间和当天专注统计。最近连续完成四次专注，且三段完整间隔累计不超过 `20` 分钟时，页面底部会低调提示可以考虑延长休息；不会自动改变时长。
- 休息运行时，`←/→` 调整 `-1/+1` 分钟，`↓/↑` 调整 `-5/+5` 分钟，空格增加 `1` 分钟，`Ctrl+Space` 不执行操作；减时会使剩余时间不大于零时忽略。其他非修饰键或鼠标点击只关闭页面，不会暂停或结束后台休息。
- 点击顶栏图标中的“开始专注…”会打开低饱和番茄红全屏启动页；启动应用本身只显示顶栏图标。页面中央以与休息页一致的大号计时显示本次时长，下方为“开始专注”按钮，并记住本次运行中最近使用的时长。可直接输入 `1–720` 分钟、用左右键调整 `±1` 分钟、上下键调整 `±5` 分钟，Enter 开始、Esc 退出。
- 顶栏默认不显示数字倒计时；可通过配置仅在最后若干分钟显示。
- GNOME 顶栏底边使用 `3` 个逻辑像素的静态色带表示状态；全屏时自动隐藏。
- 专注可暂停或提前结束，休息可提前结束；休息不会暂停，并会按实际经过时间继续计时。
- 提前结束专注时，已满 `5` 分钟才计入实际专注时长（不增加完成次数），随后准备“实际专注时长 ÷ 5”的缩短休息；不足 `5` 分钟则不记录并直接回到等待开始。
- 只保存本地每日完成次数和实际专注时长，不联网。

##### 休息屏保逻辑

专注完成后，等待休息状态和本次时长会持久化，但不会随墙上时间减少。点击系统通知或顶栏的“开始休息”后才创建倒计时截止时间并打开黑色全屏页。打开休息屏保只是显示层，不会暂停休息；关闭后可从顶栏“休息中”反复打开。休息结束时，如果屏保仍在前台，会自动切换到下一轮专注的启动页；否则回到等待状态。应用重启或系统挂起后，已开始的休息仍依据持久化的墙上时钟截止时间继续计算。

##### Ubuntu 22.04 依赖

```bash
sudo apt install python3 python3-gi gir1.2-gtk-3.0 gir1.2-notify-0.7 \
  gir1.2-ayatanaappindicator3-0.1 python3-tomli
```

GNOME 需要启用 AppIndicator 支持；Ubuntu 桌面通常已预装并启用。

##### 从源码运行

```bash
./bin/focus-tomato
```

##### 用户级安装

安装到 `~/.local`，同时创建应用菜单入口和 XDG 自动启动项：

```bash
./install.sh
```

卸载程序但保留配置和记录：

```bash
./uninstall.sh
```

##### 配置

首次运行会生成 `~/.config/focus-tomato/config.toml`：

```toml
focus_minutes = 25
short_break_minutes = 5
long_break_minutes = 15
sessions_before_long_break = 4
countdown_visible_minutes = 0
show_progress_ring = false
show_state_band = true
autostart = true
```

`show_progress_ring` 控制顶栏图标是否用八级圆环表达大致剩余比例。
默认关闭，避免带来倒计时压力。`show_state_band` 可以关闭状态色带；
`countdown_visible_minutes = 0` 表示完全不在顶栏显示数字倒计时。

色带使用低饱和度颜色：番茄红表示专注、绿色表示休息、琥珀色表示暂停，
等待开始和等待休息状态不显示。色带覆盖在 GNOME 已有顶栏内，
不会改变窗口工作区尺寸，也不接收鼠标事件。分数缩放下高度按逻辑像素计算。

配置中的 `focus_minutes` 仍是计时引擎的默认专注时长；全屏启动页按交互约定优先使用本次运行最近输入的时长，否则为 `25` 分钟。`short_break_minutes` 是每次正常休息的初始时长，临时调整不会带入下一轮；`long_break_minutes` 只作为连续专注提示中的建议时长，`sessions_before_long_break` 控制提示检查的专注次数。每轮临时输入不会改写配置。
自定义时长会随正在进行的阶段写入数据库，因此暂停的专注或正在进行的休息在异常重启后仍可正确恢复，圆环比例也以该轮实际总时长计算。

其他配置修改在下一阶段生效。将 `autostart` 设为 `false` 后，下次登录不会自动启动。记录保存在 XDG 用户数据目录下的 `focus-tomato` 目录中。

##### 构建 Debian 包

```bash
./build-deb.sh
sudo apt install ./dist/focus-tomato_0.3.0_all.deb
```

生成的包为纯 Python `all` 架构包，运行依赖由 APT 管理。
